# Cabinet agents

**Status: draft.**

An agent ("Cabinet" advisor) is a charter file under `charters/<id>.md`:
frontmatter (`id`, `name`, `title`, `aliases`, tool allow/deny lists) plus a
short mission in prose. The starter set in this repo is generic — no family
facts, no real house details.

Addressing in chat: `@cto is the service up`, or `ask my cfo what we spent`.
An address is a one-turn persona switch unless the owner says to stick with
that advisor for the rest of the conversation.

A new tool made available by a code upgrade stays off for every agent until
the owner explicitly turns it on through the Board.
